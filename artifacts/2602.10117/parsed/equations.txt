J.4 Practitioner Guidance

Based on our analysis, we offer the following guidance for practitioners:

Cost Scaling

The dominant cost factors are:

Variation responses ( 69 %of total): Scales with N concepts × N inputs × N target models

Baseline verbalization ( 2 %of total): Scales with N concepts × N inputs × N target models

Variations generation ( 25 %of total): Scales with N concepts × N inputs (one-time cost)

Cost Optimization Strategies

Reduce input count : Clustering inputs and using representatives can significantly reduce costs while maintaining coverage

Batch API for preparation : Always use batch API ( 50 %discount) for dataset preparation steps

Use smaller target models : Open-weight models (Gemma) are 10 -100 × cheaper than proprietary models (Claude)

Early stopping : The sequential testing design with efficacy and futility stopping saves approximately 40 %on variation testing
